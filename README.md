# Voxel Noel 🎄

Cây thông Noel 3D dạng voxel trên đảo tuyết lơ lửng — Three.js, bloom, đổ bóng, pháo hoa voxel và lời chúc tuỳ chỉnh.

- `index.html` — bản voxel 3D (mở trang là chạy)
- `ascii.html` — bản ASCII

Thêm lời chúc vào link: `…/#Chuc%20ban%20Noel%20vui%20ve`

Phím tắt: `F` pháo hoa · `R` phát lại · kéo để xoay · cuộn/chụm để zoom.
